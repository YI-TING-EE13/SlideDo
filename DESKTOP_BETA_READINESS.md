# SlideDo Desktop Public Beta Readiness

This file tracks the desktop public-beta handoff materials that are not covered
by Java compilation alone. Keep it aligned with the desktop package generated by
`package-desktop.bat`.

## Current Beta Target

- Version source: `version.properties`
- Current version: `0.2.0-beta.1`
- Package artifact: `dist/desktop/SlideDo-0.2.0-beta.1.zip`
- Optional app-image artifact: `dist/desktop/app-image/SlideDo`
- Runtime target: Java 17 or newer
- Save location: `%APPDATA%\SlideDo` on Windows, `<user.home>/.slidedo` on
  other platforms

## Public Beta Blockers

- Choose the public distribution location and download page.
- Decide whether the beta needs a signed installer before wider distribution.
- Run and record the manual desktop smoke checklist below on the final package.
- Run and record the manual desktop accessibility review below.
- Confirm the final release notes and known limits are acceptable for testers.

## Package Contents

The desktop ZIP must contain:

- `SlideDo.jar`
- `SlideDo.bat`
- `README.txt`
- `RELEASE_NOTES.md`

`README.txt` must tell testers how to start the app and where local saves and
records are stored. `RELEASE_NOTES.md` must match the version in
`version.properties`.

## Tester Instructions Draft

Use this as source text for a public beta page or release post.

```text
SlideDo Desktop Beta

Download and extract the ZIP package, then run SlideDo.bat.

Requirements:
- Windows 10 or newer
- Java 17 or newer available on PATH

What to test:
- Start a new 3x3, 4x4, and 5x5 puzzle.
- Click adjacent and non-adjacent aligned tiles.
- Verify whole-row and whole-column slides count as one move.
- Undo after a whole-line slide.
- Restart the current puzzle.
- Save, close, reopen, and load the saved puzzle.
- Open How to Play, Practice Tutorial, Records, and Preferences.
- Toggle reduced motion and confirm board movement still obeys the same rules.
- Solve a small puzzle and review the Results wording.

Known limits:
- The beta ZIP is not a signed installer.
- Saves and records are local to this computer.
- Solver actions can be expensive on larger boards.
```

## Manual Desktop Smoke Checklist

Run this checklist from the final extracted ZIP, not from the development tree.

- Launch with `SlideDo.bat`.
- Home opens before the board.
- New 3x3, 4x4, and 5x5 games start correctly.
- Clicking an adjacent aligned tile moves one tile.
- Clicking a non-adjacent aligned tile slides the full row or column.
- Whole-line slide increments the move count once.
- Undo after whole-line slide restores the previous board in one step.
- Restart restores the original puzzle and resets moves/timer.
- Save, exit, relaunch, and Load restore board, moves, elapsed time, and restart
  state.
- Records shows best records by size and explains player-only record policy.
- Preferences opens and reduced motion can be toggled.
- How to Play and Practice Tutorial text match Android's teaching flow.
- Solver-assisted completion does not replace player records.

## Manual Desktop Accessibility Review

- Keyboard shortcuts work for New Game, Undo, Restart, Save, Load, and Exit.
- Arrow keys move the empty cell one step.
- Menu labels and dialog titles are readable at default Windows scaling.
- Reduced motion removes board transition animation without changing rules.
- Focus can move through Home, dialogs, and primary controls.
- Color contrast is readable for board tiles, highlighted assist tiles, and
  status text.
- Text is not clipped at 100%, 125%, and 150% Windows display scaling.

## Release Checklist

Before opening desktop public beta:

- Run `verify.bat`.
- Run `package-desktop.bat`.
- Run `check-desktop-beta-readiness.bat`.
- Run `verify-release.bat`; it also runs the desktop beta readiness check.
- Confirm `dist/desktop/SlideDo-<version>.zip` opens and contains the required
  files.
- Confirm the release artifact manifest includes the desktop ZIP SHA-256 hash.
- Confirm no local save files are included in the ZIP.
- Publish the beta download page with the tester instructions and known limits.
